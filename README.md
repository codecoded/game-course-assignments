# Game course assignments · Sky Rumsey

All work for the course, built around one game: **_The Suborned_**, a single-player real-time tactics and social-infiltration game for PC (Unity). You lead a covert four-person cell in a bright retro-future city, and the city carries out your plan without knowing it.

| # | Assignment | What's here |
|---|---|---|
| 1 | [GDD draft](assignment-01-gdd-draft/) | v0.9.18 as submitted (PDF + HTML), plus the 24 Sep v0.9 working draft |
| 2 | [GDD final](assignment-02-gdd-final/) | v0.12.0: the 6-page submission, the full GDD, the agentic design document (ADD) and the changelog |
| 3 | [Build an agent crew](assignment-03-agent-crew/) | five Claude Code agents, cut from the ADD, that generate a rule-checked mission on the capstone's own block. `cd assignment-03-agent-crew && bun install && bun test` |

Each folder stands alone, with its own README. The documents build on each other: assignment 2 is the redesign that review of assignment 1 drove (see its changelog), and assignment 3's agents are cut from assignment 2's ADD and design missions inside the game's world.
